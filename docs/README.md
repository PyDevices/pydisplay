# pydevices-examples documentation

This repository is a **showcase**, not a product. The product — the board
contract, core packages, drivers, installation, and platform notes — is
documented in [pydevices/docs](https://github.com/PyDevices/pydevices/tree/main/docs).

What lives here:

- [peterhinch-guis.md](peterhinch-guis.md) — running Peter Hinch's Nano-GUI,
  Micro-GUI, and MicroPython-Touch on PyDevices hardware.
- [tft-gui.md](tft-gui.md) — the @russhughes TFT GUI stub.
- [screenshots/](screenshots/README.md) — captured example output.

Code-adjacent docs:

- [tools/README.md](../tools/README.md) — the example test matrix, PyScript and
  Playwright debugging, the LVGL timer harnesses, and IDE typings.
- [lib/utils/README.md](../lib/utils/README.md) — the optional `utils` modules.
- [scripts/README.md](../scripts/README.md), [tests/README.md](../tests/README.md)
