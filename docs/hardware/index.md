# Hardware setup

Board configs, drivers, and the board-devices contract docs live in
**[pydevices](https://github.com/PyDevices/pydevices)**
and are published on GitHub Pages (markdown → HTML, not Read the Docs):

**[pydevices.github.io/pydevices](https://pydevices.github.io/pydevices/)**

| Topic | Page |
|-------|------|
| Board configs | [board-configs](https://pydevices.github.io/pydevices/board-configs.html) |
| Board devices contract | [board-devices](https://pydevices.github.io/pydevices/board-devices.html) |
| Display / touch drivers | [display-drivers](https://pydevices.github.io/pydevices/display-drivers.html), [touch-drivers](https://pydevices.github.io/pydevices/touch-drivers.html) |
| Device matrix | [device-matrix](https://pydevices.github.io/pydevices/device-matrix.html) |

pydevices-examples still documents how apps use those boards:

- [Runtime](../concepts/runtime.md) — `display_drv` / `runtime` / touch read
- [Config files](../concepts/config-files.md) — `board_config.py` and add-on templates
